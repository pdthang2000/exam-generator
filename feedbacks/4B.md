# Phase 4B Feedback

## 1. Chat UI — Multi-document selection (FIXED)

**Original report:** Chat sidebar allowed selecting multiple documents.

**Resolution:** Changed to single-document selection. Clicking a document selects it (deselects the previous one); clicking again deselects it. Backend `chat.py` now accepts `document_id` (single int) instead of `document_ids` (array). The `$in` filter logic was removed.

**Files changed:** `static/index.html`, `chat.py`, `app.py`

## 2. Exam page — Missing interactive quiz mode

**Status:** Valid — this is Phase 4C (not yet implemented).

Currently, after generating questions on `exam.html`, the results are displayed as a read-only preview with answers and explanations visible. There is no way for the creator to actually take the quiz interactively.

Phase 4C will add:
- **Practice mode**: one question at a time, immediate feedback after each answer
- **Exam mode**: all questions shown, graded on submit
- Results view with score and per-question breakdown
- Post-quiz actions (save, export results, retake, new exam)
